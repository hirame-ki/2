개인정보처리방침

쌤보드(SsamBoard) · 시행일 2026년 9월 20일

쌤보드는 교사를 위한 무료 윈도우 바탕화면 위젯 프로그램입니다. 이 방침은 쌤보드가 이용자의 정보를 어떻게 다루는지 설명합니다.

핵심 요약
쌤보드는 개발자 서버를 운영하지 않습니다. 이용자가 입력한 모든 자료는 이용자 본인의 컴퓨터에만 저장되며, 개발자는 그 내용을 열람할 수 없습니다.

1. 저장하는 정보와 저장 위치

학교 설정, 시간표, 명렬표, 성적·상담·진도 기록 등 쌤보드에서 입력하는 모든 자료는 이용자 컴퓨터의 앱 데이터 폴더에 파일로 저장됩니다. 개발자에게 전송되지 않으며, 별도의 회원가입이나 계정도 없습니다.

프로그램을 삭제하거나 해당 폴더를 지우면 자료도 함께 사라집니다.

2. 구글 계정 연동 (휴대폰 연동 기능)

이용자가 설정에서 직접 연결한 경우에만 동작하는 선택 기능입니다.

요청하는 권한

권한용도
.../auth/calendar.app.created 쌤보드가 직접 만든 "쌤보드" 캘린더에 일정을 등록·수정·삭제합니다. 이용자의 기존 캘린더는 읽을 수도, 수정할 수도 없습니다.
openid, .../auth/userinfo.email 연결된 계정을 설정 화면에 표시하기 위해 이메일 주소를 확인합니다.

전송되는 내용

설정에서 켜 둔 항목만 전송됩니다. 달력 위젯에 등록한 일정, 학급 이벤트, NEIS 학사일정, 학생 생일 중에서 이용자가 직접 선택합니다. 학생 생일을 켜면 학생 이름이 이용자 본인의 구글 계정에 저장되므로, 필요하지 않다면 꺼 두시기 바랍니다.

성적, 상담 기록, 학생부 자료는 어떤 경우에도 전송되지 않습니다.

데이터가 오가는 경로

이용자 컴퓨터와 이용자 본인의 구글 계정 사이에서만 직접 통신합니다. 개발자 서버를 거치지 않으며, 개발자는 전송 내용을 알 수 없습니다.

인증 정보 보관

구글이 발급한 인증 토큰은 운영체제의 암호화 기능(Windows DPAPI)으로 암호화해 이용자 컴퓨터에만 저장합니다. 외부로 전송되지 않습니다.

구글 사용자 데이터 이용 제한

쌤보드가 구글 API로 얻은 정보의 이용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다. 해당 정보는 이용자에게 기능을 제공하는 목적에만 사용하며, 광고에 쓰거나 제3자에게 판매하지 않고, 인공지능 모델 학습에 사용하지 않습니다.

연결 해제 방법

  • 쌤보드 설정 → 휴대폰 연동 → 연결 해제
  • 또는 구글 계정 보안 설정에서 쌤보드 액세스 권한 삭제

연결을 해제해도 구글 캘린더에 이미 올라간 "쌤보드" 캘린더는 남아 있습니다. 필요하면 구글 캘린더에서 해당 캘린더를 직접 삭제하시면 됩니다.

3. 외부 서비스 연동

이용자가 해당 기능을 사용할 때만 필요한 정보가 각 서비스로 전달됩니다.

서비스전달되는 정보
NEIS 교육정보 개방 포털학교 코드 (급식·학사일정 조회)
컴시간알리미학교 코드 (시간표 조회)
날씨 정보 서비스이용자가 지정한 지역명
Groq, NVIDIA (AI 기능)이용자가 AI 도구에 입력한 문장. 문제변형기·공문서 도우미·규정나침반·기록 정리 도우미 사용 시에만 해당
구글 캘린더위 2항 참고

AI 기능에 학생 실명이나 민감한 개인정보를 입력하지 않도록 주의해 주시기 바랍니다.

4. 개인정보 보호책임자

쌤보드는 이용자의 개인정보를 수집·보관하지 않으므로 별도의 처리 위탁이나 제3자 제공이 없습니다. 이 방침과 관련한 문의는 아래로 연락해 주십시오.
