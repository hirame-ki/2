Features
교사의 하루를 더 가볍게
H-Factory는 교사의 일상 업무를 돕기 위해 설계된 위젯 앱입니다. 설치하고 바탕화면에 올려두기만 하면 됩니다.
Feature 00 · New
⚡
교무비서 펫 '번뜩이'
화면 오른쪽 아래를 돌아다니는 픽셀 펫이 수업 시작 전·급식·마감 할 일·디데이·학생 생일·시간표 변경을 먼저 알려 주고, "내일 일정", "금요일 급식"처럼 물으면 바로 답합니다. "3-1 아이유 내일 결석", "16일에 체험학습 등록해줘", "2반 3명 뽑아줘"처럼 말로 부탁하면 명렬표·학사일정·수업도구를 직접 처리하고, 그 밖의 질문은 AI가 답합니다. 쓸수록 레벨이 올라 소품이 생깁니다. 캐릭터 5종·16가지 동작. v2.9.0 신규
Feature 01
📱
휴대폰 연동
구글 계정을 한 번 연결하면 PC의 할 일·학사일정·급식·시간표·출결·진도·상담 일지를 휴대폰에서 그대로 확인하고 입력합니다. 학사일정은 PC처럼 달력으로 보고, 위젯과 아래 메뉴는 직접 고릅니다. 앱 설치 없이 홈 화면에 추가해 쓰고, 고친 내용은 PC로 돌아옵니다. 출결은 지각·조퇴·결과 교시까지 휴대폰에서 기록합니다.

Feature 05
🗂️

상담 일지, 진도 체크, 성적 분석, 공문서 도우미, 생기부 초안 생성, 규정나침반, 기록 정리 도우미까지. 교사의 핵심 업무를 AI로 빠르게 처리할 수 있는 총 12가지 도구를 별도 창에서 사용합니다.

How to Install
설치 방법은 단 4단계
Step 01
🔗
다운로드 페이지 열기
아래 다운로드 버튼을 클릭하면 GitHub Releases 페이지로 이동합니다. 로그인 없이 누구나 무료로 받을 수 있습니다.
Step 02
📦
.exe 파일 다운로드
페이지 하단 Assets 목록에서 SsamBoard.Setup.x.x.x.exe 파일만 클릭하여 받으세요. 다른 파일(.blockmap, .yml 등)은 필요 없습니다.
Step 03
🛡️
Windows 보안 경고 허용
처음 실행 시 파란색 보안 경고 팝업이 나타날 수 있습니다. "추가 정보"를 클릭한 후 "실행"을 누르면 됩니다. 악성 소프트웨어가 아니니 안심하세요.
Step 04
🎉
바탕화면에서 시작!
설치가 완료되면 H-Factory가 바탕화면 위에 바로 실행됩니다. 이후 업데이트는 앱에서 자동으로 알려줍니다.
⚠️
파일이 "확인되지 않음 XXXXXX.crdownload"로 저장되나요?
Chrome/Edge 브라우저가 .exe 파일을 위험하다고 판단해 차단한 것입니다. 실제 악성 소프트웨어가 아니니 안심하세요. 아래 세 가지 방법 중 하나로 해결할 수 있습니다.

방법 1 — 파일 이름 바꾸기 (가장 빠름)
다운로드 폴더에서 .crdownload 파일을 우클릭 → 이름 바꾸기 → SsamBoard.Setup.exe 로 변경 → 확장자 경고 팝업에서 예 클릭 → 실행

방법 2 — 브라우저 다운로드 목록에서 허용
Chrome 주소창에 chrome://downloads 입력 → 해당 파일 옆 ⋮ 메뉴 → 유지 또는 허용 클릭

What's New · v2.9.0
새 기능 사용법

v2.9.0에서는 교무비서 펫 '번뜩이'가 새로 생겼고, 명렬표 출결을 교시 단위로 기록할 수 있게 되었습니다. 일부 업무도구의 AI 모델도 새로 바꿨습니다.

⚡
교무비서 펫 '번뜩이'

제작자 닉네임 hirameki(번뜩이다)에서 이름을 딴 픽셀 펫이 화면 오른쪽 아래를 돌아다니며 일정을 챙기고, 말로 부탁하면 바로 처리하고, 물어보면 답합니다. 펫에게 "도움말" 또는 "뭐 할 수 있어?"라고 물으면 할 수 있는 일을 모두 알려 줍니다. 설정 항목과 할 수 있는 일을 한 장에 모은 교무비서(펫) 안내 →

시작하기
  1. 설치하면 펫이 바로 나타납니다. 설정 › 펫에서 켜고 끌 수 있습니다
  2. 캐릭터 5종(번뜩이·스파키·몽글이·말랑이·냥이)과 색상, 크기(48·72·96px)를 고릅니다
  3. 말 거는 정도(조용히·보통·수다쟁이), 수업 중 동작(말만 멈추기·숨기기·평소대로), 방해 금지 시간, 먼저 알려 줄 알림 종류를 정합니다
  4. 펫을 한 번 누르면 메뉴와 입력칸이, 말풍선의 ⤢를 누르면 큰 대화창이 열립니다
먼저 알려 줘요
  • 아침 인사: 날씨·오늘 수업·일정·디데이·학생 생일 요약
  • 수업 시작 전(팔레트 알림과 같은 시각, 기본 2분 전) · 점심 급식 · 마감 할 일(10시·2시) · 디데이(7·3·1일 전, 당일) · 내일 일정(3시 반) · 퇴근 인사
  • 조회 뒤 출결 확인: 오늘 출결 기록이 없으면 물어보고 "모두 출석이에요"로 답할 수 있습니다
  • 학생 생일: 이벤트 플래너에 넣어 둔 학생 생일을 아침에 알려 줍니다
  • 시간표 바뀜: 컴시간알리미 시간표가 바뀌면 "내일 3교시 수학 → 체육"처럼 바로 알려 줍니다
  • 체육 날씨: 체육 1시간 전, 미세먼지 나쁨·비·폭염·한파면 실내 수업을 권합니다
  • 출결 흐름: 3일 연속 결석, 이번 달 3번째 이상 지각인 학생을 짚어 줍니다
  • 상담 다시 챙기기: 상담하고 2주가 지난 학생을 수업이 끝난 오후에 알려 줍니다
  • 금요일 한 주 돌아보기: 이번 주 수업 시간·완료한 할 일·다음 주 일정을 정리해 줍니다
  • 설정 › 알림의 '펫이 켜져 있으면 펫이 대신 알리기'를 켜 두면 수업 전·점심·퇴근·아침 알림을 팝업 대신 펫이 말해 줍니다 (펫이 꺼져 있거나 접혀 있으면 팝업으로)
말로 부탁하세요 (바로 실행, 잘못되면 [되돌리기])
  • 할 일: "할 일 추가 학습지 인쇄 내일까지", "가정통신문 결재 등록해줘", "학습지 인쇄 끝냈어"
  • 학사일정·디데이: "16일에 '체험학습' 등록해줘", "10월 30일 협의회 일정 추가", "디데이 추가 수능 11월 19일" — 긴 문장에서도 이름만 쏙 뽑아 등록합니다
  • 지우기: "16일 체험학습 일정 삭제해줘", "할 일에서 보고서 지워줘", "디데이 수능 삭제"
  • 출결: "3-1 아이유 내일 결석", "김철수 3교시 조퇴 기록해줘", "아이유 결석 취소" — 성을 빼고 "민지 지각"이라 하면 "김민지 학생인가요?" 하고 되물은 뒤 기록합니다
  • 출결 조회: "오늘 결석 누구야", "지난주 출결", "아이유 이번 달 지각 몇 번"
  • 상담·진도: "아이유 상담 기록: 교우 관계 고민", "3반 국어 2단원 3차시 완료", "진도 어디까지야"
  • 메모·포스트잇: "메모에 회의 자료 준비 적어줘", "노란 포스트잇에 학부모 전화 붙여줘", "2번 포스트잇 떼줘"
  • 알림: "10분 뒤에 회의 알려줘", "3시 반에 학부모 전화 알려줘"
  • 수업도구 바로 실행: "2반 3명 뽑아줘", "타이머 5분", "모둠 4개로 나눠줘", "룰렛 돌려줘", "백색소음 틀어줘"
  • 열고 닫기: "상담일지 열어줘", "규정나침반 열어줘", "나이스 열어줘"(바로가기 이름), "다 닫아줘"
  • 여러 개 한 번에: "상담일지 열고 아이유 결석 기록해줘"
  • 집중 타이머: "25분 집중" — 끝나면 쉬는 시간도 챙겨 줍니다. "집중 그만"으로 멈춥니다
물어보세요
  • 일정: "내일 일정", "다음 주 일정", "15일 일정", "중간고사 언제야"
  • 급식·시간표: "금요일 급식", "내일 석식", "목요일 3교시", "다음 수업", "우리 반 시간표"
  • 날씨: "내일 날씨", "우산 챙겨야 해?", "미세먼지"
  • 그 밖의 무엇이든: 개념 설명, 수업 아이디어, 학생 지도 방법, 상담 멘트, 문구 다듬기는 AI가 답합니다. "두 번째 거 더 자세히"처럼 이어서 물어도 됩니다
함께 자라요 (펫 성장)
  • 할 일 완료·부탁 처리·쓰다듬기·집중 타이머로 경험치가 쌓여 최대 10레벨까지 자랍니다. 캐릭터를 바꿔도 레벨은 그대로입니다
  • 레벨이 오르면 소품이 열립니다: 🎀 리본 · 🌸 꽃 · ⭐ 별 머리핀 · 👑 왕관(머리) → 🍭 막대사탕 · 🎈 풍선(손) → 🪽 천사 날개 · 😇 천사 고리 → 10레벨 ✨ 아우라
  • "레벨", "풍선 들어줘", "날개 빼줘", "소품 바꿔줘", "소품 다 벗어"로 소품을 고릅니다
  • 계절 모자: 할로윈엔 마녀 모자, 크리스마스엔 산타 모자, 새해·설날엔 고깔모자를 씁니다
  • 비 오면 우산, 추우면 목도리, 덥고 맑으면 선글라스를 합니다
같이 놀기
  • 펫을 두 번 누르거나 문지르면 쓰다듬기, 끌면 들어서 옮길 수 있습니다
  • 가끔 친구 펫이 놀러 와 술래잡기·춤·포옹·커피 타임을 합니다. "친구 불러줘"라고 해도 옵니다
  • 걷기·달리기·독서·커피·춤·잠 등 16가지 동작과 무작위 표정으로 쉬지 않고 움직이고, 동작마다 "총총총~", "하아아암~" 같은 글씨가 뜹니다(설정 › 펫 '동작 글씨'에서 끄기·빈도 조절)
보기 편하게
  • 글씨 크기: 말풍선 위 가− 가+, Ctrl + 마우스 휠, 또는 "글씨 크게 해줘". 노트북·고해상도 모니터는 설정 › 펫의 모니터 배율에 맞추기로 자동으로 키웁니다
  • 입력칸을 누르면 자판이 한글로 바뀌어 바로 칠 수 있습니다
  • 펫이 다른 창 위에 있어도 눌러서 쓸 수 있고, 눌러도 쓰던 창의 입력이 끊기지 않습니다
AI와 개인정보
  • 자유 질문은 설정 › AI API의 Groq 키로 먼저(가장 빠름) 답하고, 한도에 걸리거나 안 되면 NVIDIA 키로 넘어갑니다 (둘 다 무료)
  • AI에는 선생님의 시간표·할 일·디데이·일정·급식·날씨만 보냅니다. 명렬표·출결·상담 같은 학생 정보는 보내지 않고, 출결·상담·진도 부탁은 컴퓨터 안에서만 처리합니다
  • 메모는 학생 이름이 섞일 수 있어 설정에서 따로 켠 경우에만 보냅니다
숨기기
  • 펫에 마우스를 올리면 나오는 접기 버튼, 또는 트레이 메뉴 번뜩이 접기/펼치기
  • PPT 슬라이드쇼·전체화면 영상 중에는 자동으로 숨었다가 끝나면 돌아옵니다. 화면 녹화(캡처 도구·캡컷·OBS 등) 중에는 숨지 않아 펫을 함께 찍을 수 있습니다

명렬표 출결 교시 기록

학생을 눌러 출결을 고르면 그날의 교시(조회~종례) 버튼이 나타나, 교실에 없었던 교시를 남길 수 있습니다. 휴대폰에서도 같은 방식으로 기록됩니다.

교시가 정해지는 방식
  • 결석: 조회부터 종례까지 모든 교시가 자동으로 결석 처리됩니다
  • 지각: 3교시를 누르면 조회·1·2·3교시가 지각으로 표시됩니다
  • 조퇴: 3교시를 누르면 3교시부터 종례까지 표시됩니다
  • 결과: 누른 교시만 표시되며 여러 개를 고를 수 있습니다
엑셀 내보내기
  • 학급통계 엑셀(월별·주별·일별): '출결 상세' 시트에 날짜·번호·이름·출결·교시 범위·빠진 교시·메모가 모두 담깁니다
  • 명렬표 엑셀: 메모가 없어도 결석·지각·조퇴·결과 기록이 교시와 함께 모두 내보내집니다

기본 사용법

  4. 저장된 상담 기록은 날짜 역순으로 타임라인 형식으로 표시됩니다
주요 기능
  • 상담 횟수 배지: 학생 목록에서 각 학생의 누적 상담 횟수 확인 가능
  • 이름 검색: 상단 검색창으로 학생 빠르게 찾기
  • 상담 유형 색상 코딩: 학업(파랑) / 생활(초록) / 진로(주황) / 기타(회색)
  • 엑셀 내보내기: 전체 학생 요약 시트 + 학생별 개별 시트로 내보내기 가능
  • 기록 수정: 타임라인의 각 기록에서 수정·삭제 가능
학부모 상담 프롬프트 생성 (v2.7.10)

성적 분석

NEIS에서 내보낸 성적 파일을 분석하여 학생별 성적 변화 추이와 AI 상담 프롬프트를 생성하는 도구입니다. 교과학습발달상황과 전과목 성적 일람표(1차 정기고사) 두 가지 파일 형식을 모두 지원합니다.

엑셀 파일 다운로드 방법 (NEIS)
① 교과학습발달상황: 나이스 ▸ 학급담임 ▸ 학교생활기록부 ▸ 학생부 항목별 조회 ▸ 교과학습발달상황(전체학생)
② 전과목 성적 일람표: 나이스 ▸ 학급담임 ▸ 성적조회/통계 ▸ 학기말성적조회 ▸ 성적일람표 전과목 (산출기준: 1차 정기시험 / 받은점수기준)

위 경로에서 .xlsx 파일을 다운로드하여 사용합니다.

사용 방법
  1. 파일 종류 칩에서 교과학습발달상황 또는 전과목 성적 일람표 선택
  2. 업로드 존에 NEIS 성적 파일(.xlsx)을 드래그하거나 클릭하여 선택
  3. 드롭다운에서 분석할 학생 선택
  4. 원하는 과목 칩을 선택/해제하여 분석 범위 지정
  5. 학생의 진로 희망 직업/계열 입력 (선택)
  6. 📊 분석 & 프롬프트 생성 버튼 클릭
분석 결과
  • 학생 요약: 분석 과목 수, 평균 등급, 최고/최저 등급 요약 카드
  • 가상등급 분석 (일람표 전용): 원점수·석차 기반으로 가상 5등급(고1~2) · 9등급(고3) 자동 산출. 한 등급 올리기 위해 앞에 있는 학생이 몇 명인지 과목별로 표시
  • 아쉬운 과목 순위: 추월 인원이 적은 과목 순으로 정렬 → 어떤 과목에 집중하면 효율적으로 등급을 올릴 수 있는지 한눈에 파악, 상담 자료로 바로 활용
  • 성적 변화 추이 그래프: 계열별(전체/국어/수학/영어/사회/과학/기타) 탭으로 선 그래프 확인
  • AI 상담 프롬프트 자동 생성: Claude, ChatGPT, Gemini에 붙여넣어 성적 분석·진로 추천·상담 포인트를 받을 수 있습니다
  • 엑셀 다운로드: 분석 결과를 .xlsx 파일로 저장 가능
⚠️5등급제(고1~2 공통과목)와 9등급제(고3 선택과목)를 자동으로 감지하여 적용합니다.

수업자료 생성

2022 개정교육과정 전체 성취기준(중학교 25과목 + 고등학교 151과목)이 내장된 AI 프롬프트 생성기입니다. 수업 주제와 성취기준을 선택하면 수업 자료 프롬프트를 자동으로 만들어 줍니다.

생성 가능한 자료
  • ① 수업 PPT 슬라이드 — HTML/CSS 웹 슬라이드 형식으로 Claude가 직접 생성
  • ② 교사 발문 — 밑줄·색깔 강조가 포함된 Word 문서
  • ③ 학생 활동지 — 바로 사용 가능한 Word 문서
  • 그 외: OX퀴즈·수행평가·토론·모둠활동지·롤플레이·카드뉴스·개념노트·웹게임 등
사용 방법
  1. ① 과목·내용·성취기준 탭에서 학교급·과목·학년·수업 주제 선택
  2. 성취기준 목록에서 해당 기준 클릭하여 선택 (선택 사항)
  3. ② 자료형태 탭에서 원하는 결과물 칩 선택
  4. ③ 세부설정 탭에서 교수법·난이도·어조·디자인 테마 설정
  5. ④ 생성 탭에서 ✨ 프롬프트 생성하기 클릭 → 자동 복사
  6. claude.ai에서 Ctrl+V로 붙여넣기 — 기존 학습지·PPT도 함께 업로드하면 더 높은 완성도
💡모든 프롬프트에 할루시네이션 방지 지침이 자동으로 포함됩니다. 생성 기록은 최대 20개까지 저장됩니다.

수행평가 채점표

지필·수행 항목별 반영비율을 설정하고 점수를 입력하면 100점 환산 점수, 등수, 등급을 자동으로 산출합니다. 엑셀 양식 다운로드 후 점수를 입력해 업로드하는 방식도 지원합니다.

기본 사용법
  1. 항목 설정 탭에서 평가 항목(예: 지필1, 수행1)과 만점, 반영비율(%) 입력 — 합계가 100%가 되도록 설정
  2. 채점표 탭에서 반 선택 → 명렬표에서 학생 자동 불러오기
  3. 각 학생의 항목별 점수 직접 입력 또는 엑셀 업로드로 일괄 입력
  4. 상단 성적산출 버튼 클릭 → 환산점수·등수·등급 자동 계산
  5. 필요 시 엑셀 내보내기로 결과 저장
주요 기능
  • 반영비율 환산: 각 항목 점수 ÷ 만점 × 반영비율 합산 → 100점 기준 환산점수 자동 계산
  • 등급 선택: 9등급제 / 5등급제 그때그때 선택 가능 (고3↔나머지 학년 유연하게 사용)
  • 정렬: 번호순 / 등수순 / 점수순 토글
  • 엑셀 양식 다운로드: 반 학생 명단이 포함된 입력 양식 생성 → 작성 후 업로드로 점수 일괄 적용
  • 통계 표시: 성적산출 후 인원·평균·최고·최저 요약
💡항목 설정과 점수 데이터는 브라우저 로컬스토리지에 저장됩니다. 창을 닫고 다시 열어도 유지됩니다.

학급 이벤트 플래너

학급 행사, 시험, 체험학습, 학생 생일 등을 등록하고 D-DAY 위젯에 자동 연동합니다. 당일 앱 실행 시 팝업 알림도 제공합니다.

기본 사용법
  1. 이벤트 추가 탭에서 이름·날짜·유형·관련 반 입력
  2. 디데이 위젯에 자동 등록 토글 켜고 등록 → D-DAY 위젯에 즉시 반영
  3. 생일 관리 탭에서 학생 이름·생일(MM-DD) 입력 → 올해/내년 기준 날짜 자동 계산 후 D-DAY 등록
  4. 이벤트 목록에서 미등록 이벤트는 📌 버튼으로 언제든 D-DAY에 추가 가능
주요 기능
  • D-DAY 자동 연동: 등록한 이벤트·생일이 바탕화면 D-DAY 위젯에 실시간 반영
  • 당일 팝업 알림: 앱 실행 시 오늘 해당하는 이벤트·생일을 중앙 팝업으로 알림 (하루 1회)
  • 유형별 필터: 생일·시험·체험학습·행사·기타로 분류 및 필터링
  • 명렬표 연동: 반 선택 시 명렬표에서 학생 목록 자동 불러오기
💡생일은 MM-DD 형식(예: 03-15)으로 입력하면 올해 생일이 지났을 경우 자동으로 내년 날짜로 D-DAY를 등록합니다.

문제변형기

기존 문제를 다양한 유형·난이도로 자동 변형하는 AI 프롬프트 생성기입니다. 텍스트 직접 입력이나 파일·이미지 업로드를 지원합니다.

사용 방법
  1. 입력 방식 선택 (직접 입력 / 파일 업로드 / 이미지 업로드)
  2. 변형할 문제 입력 또는 파일·이미지 업로드
  3. 변형 유형 선택 (객관식↔서술형, 빈칸완성, OX퀴즈, 유사 문제 등)
  4. 난이도 슬라이더로 원하는 수준 설정
  5. ✨ 변형 프롬프트 생성 클릭 → AI에 붙여넣기
주요 기능
  • 다양한 변형 유형: 객관식→서술형, 서술형→객관식, 빈칸완성, OX퀴즈, 유사 문제, 쉬운 풀이 등
  • 이미지 입력 지원: 시험지·교재 사진을 직접 업로드하여 문제 추출 및 변형
  • 난이도 조절: 슬라이더로 1~5단계 설정
  • 즉시 복사: 생성된 프롬프트 자동 복사 및 AI 링크 바로가기
💡이미지 업로드는 교재나 시험지 사진도 인식할 수 있습니다. Claude, ChatGPT, Gemini 모두 사용 가능합니다.

공문서 도우미

기안 초안 작성, 기안문 교정, 가정통신문 생성을 지원하는 AI 프롬프트 생성기입니다. 행정안전부 2025 공문서 편람 기준을 기반으로 합니다.

기능별 사용 방법
  • 기안 초안 작성: 문서 종류·제목·목적 입력 → 기안문 초안 프롬프트 생성
  • 기안문 교정: 작성한 기안문 텍스트 붙여넣기 → 편람 기준 교정 프롬프트 생성
  • 가정통신문 작성: 제목·목적·핵심 내용 입력 → 가정통신문 초안 프롬프트 생성
주요 기능
  • 행정안전부 편람 기준: 2025 공문서 작성 규정이 프롬프트에 자동 반영
  • 3가지 작성 모드: 기안 초안 / 교정 / 가정통신문 탭 전환
  • 즉시 복사: 생성된 프롬프트를 Claude, ChatGPT 등에 바로 붙여넣기
💡생성된 프롬프트를 AI에 붙여넣으면 학교·교사·부서 정보에 맞춘 공문서 초안을 빠르게 받을 수 있습니다.

생기부 초안 생성

학생의 활동 사례·키워드를 입력하면 생활기록부 교과 세부능력 및 특기사항 초안을 자동 생성하는 AI 프롬프트 생성기입니다.

사용 방법
  1. 학교급·과목·학년 선택
  2. 역량 도메인 선택 (학업·인성·진로 등 영역별 아코디언 메뉴)
  3. 학생 활동 사례·키워드·진로 희망 입력
  4. ✨ 생기부 초안 생성 클릭 → AI에 붙여넣기
주요 기능
  • 금지어 자동 경고: 생활기록부 작성 금지 표현을 실시간으로 경고
  • 도메인별 역량 선택: 학업·인성·진로·창체 등 영역별로 강조할 역량 선택 가능
  • 글자 수 가이드: 생기부 글자 수 제한에 맞춘 길이 목표 설정 가능
  • AI 바로가기: Claude, ChatGPT, Gemini 링크로 즉시 이동
💡학생 이름 등 개인정보는 AI에 입력하지 않도록 사례와 역량 중심으로 입력하는 것을 권장합니다.

평가 계획 작성

수행평가 영역·비율·배점 구조를 설계하면 AI가 수행평가를 추천하고 평가계획서 및 한셀 호환 채점기준표까지 생성하는 프롬프트를 자동으로 만듭니다.

사용 방법
  1. 과목·학교급·학년·학기·단원명 입력
  2. 정기고사·수행평가 반영비율(%) 슬라이더로 설정
  3. 수행평가 횟수 및 배점 구조 입력 (선택)
  4. 원하는 수행평가 방향·유형 자유 입력 (선택)
  5. ✨ 프롬프트 생성 클릭 → AI에 붙여넣기
주요 기능
  • 수행평가 AI 추천: 과목·단원·요청사항에 맞는 수행평가 유형을 AI가 먼저 추천
  • 채점기준표 자동 생성: 한셀(HanCell) 호환 엑셀 채점기준표 생성 지침 포함
  • 반영비율 자동 계산: 정기고사·수행평가 합계가 100%를 유지하도록 자동 조정
  • 현재 입력 요약: 생성 전 설정 내용 요약 카드로 최종 확인 가능
💡수행평가 요청사항을 비워두면 AI가 과목·학년·단원에 맞는 수행평가를 자동으로 제안합니다.

규정나침반

내 학교의 규정·지침 문서를 등록해 두면, 질문할 때마다 관련 조항을 근거로 제시하며 답해 주는 도구입니다.

사용 방법
  1. 설정 → AI API 탭에 NVIDIA 무료 키(nvapi-) 등록 (카드 등록 불필요)
  2. 규정·지침 파일(PDF · DOCX · HWPX · TXT)을 끌어다 놓기 — 처음 한 번만 분석
  3. 상황이나 질문을 입력하고 질의 클릭
  4. 근거 조항과 함께 답변 확인 후, 아래 채팅창에서 이어서 질문
주요 기능
  • 문서별 체크박스: 체크한 규정집에서만 답을 찾아 정확도를 높입니다
  • 근거 조항 개수 조절: 3개(빠르게) ~ 8개(두루 검토)
  • 질의 기록 자동 저장: 클릭하면 답변·근거·채팅까지 복원, 마크다운 내보내기
  • 모델 자동 전환: 사용하던 AI 모델이 종료되면 다음 모델로 자동 이어집니다
⚠️올린 문서는 분석을 위해 외부 AI 서버로 전송됩니다. 개인정보·기밀이 담긴 문서는 올리지 마세요.

기록 정리 도우미

녹음 파일을 올리거나 창에서 바로 녹음하면 전사부터 정리, 추가 질문까지 한 번에 끝내는 도구입니다.

사용 방법
  1. 설정 → AI API 탭에 Deepgram(전사)·Groq(정리) 무료 키 등록
  2. 상단에서 모드 선택 — 학생 발표 · 회의 · 상담 · 수업
  3. 녹음 파일(mp3·m4a·wav·mp4·txt 등)을 올리거나 🎙️ 바로 녹음
  4. 결과 유형·문체·형식을 고르고 정리 시작
주요 기능
  • 모드별 맞춤 정리: 회의는 안건·결정사항·후속조치, 상담은 경위·소견·추수지도, 수업은 학습목표·전개·과제
  • 자동 화자 분리: 화자1·화자2로 발언자를 구분해 전사하고 정리에도 반영
  • 결과에 이어 질문: 정리된 기록을 근거로 "결정사항만 다시 알려줘"처럼 추가 질문
  • 보관함 · 내보내기: .md / .txt 다운로드, 결과는 내 기기에만 저장
💡휴대폰의 "녹음 → 텍스트 변환" 결과(txt)를 올리면 전사 단계를 건너뛰어 훨씬 빠릅니다. 회의 녹음은 참석자 동의 하에 사용하세요.
